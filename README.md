# Morteza Management Software — راهنمای نصب و استفاده

برنامه‌ای برای مدیریت شارژ ماهانه و هزینه‌های مشاع ساختمان (۱۰ واحد).
نام نرم‌افزار: **Morteza Management Software**
کاملاً آفلاین است، هیچ اطلاعاتی به اینترنت فرستاده نمی‌شود و همه داده‌ها روی
حافظه همان گوشی/مرورگر ذخیره می‌شوند.

---

## چرا روی گوشی «نصب» نمی‌شود؟

این ایراد فایل نیست؛ **قانون امنیتی خود کروم** است. کروم اجازه نصب (Add to
Home screen به شکل اپ مستقل) را فقط به آدرس‌های امن می‌دهد:

| آدرسی که باز می‌کنید | کروم نصب می‌کند؟ |
|---|---|
| `file:///.../apartment-charge.html` (باز کردن فایل روی گوشی) | ❌ |
| `http://192.168.1.10:8443` (آدرس وای‌فای) | ❌ |
| `http://localhost` | ✅ (فقط روی همان کامپیوتر) |
| `https://...` | ✅ |

در حالت `file://` حتی گزینه «افزودن به صفحه اصلی» هم فقط یک **میان‌بر** می‌سازد
که داخل خود کروم باز می‌شود، نه یک اپ مستقل. برای نصب واقعی، برنامه باید روی یک
آدرس `https` باز شود.

> نکته: در کروم اندروید جدید، گواهی محلی که خودتان بسازید تقریباً همیشه رد
> می‌شود (Certificate Transparency)، پس روش «سرور محلی + نصب گواهی» عملاً روی
> گوشی جواب نمی‌دهد. راه درست، بردن برنامه روی یک آدرس اینترنتی `https` است.

---

## راه‌های رسیدن به آدرس https

### راه ۱ — سریع‌ترین راه (بدون ثبت‌نام)

روی همین کامپیوتر این را اجرا کنید:

```
python share_https.py
```

یک آدرس موقت مثل `https://xxxx.lhr.life` چاپ می‌شود. همان را روی گوشی باز کنید و
از منوی کروم (⋮) گزینه «نصب برنامه» را بزنید. پس از نصب، آیکون روی صفحه اصلی
می‌نشیند و برنامه **آفلاین** هم کار می‌کند. آدرس موقت با بستن پنجره از کار
می‌افتد، ولی برنامه نصب‌شده از کار نمی‌افتد.

### راه ۲ — راه دائمی و رایگان (Netlify Drop)

1. روی همین کامپیوتر اجرا کنید: `python build_publish.py`
2. پوشه `publish` ساخته می‌شود. کل **محتوای داخل** آن پوشه را بکشید و روی
   سایت `app.netlify.com/drop` رها کنید (نیاز به ثبت‌نام رایگان دارد).
3. آدرسی که می‌دهد `https` است و روی آن، کروم گزینه «نصب برنامه» را نشان می‌دهد.

### راه ۳ — GitHub Pages یا هر هاست دیگر

محتوای پوشه `publish` را روی هر جایی که `https` دارد بگذارید (GitHub Pages،
هاست خودتان، Vercel و ...). برنامه هیچ کد سمت سروری ندارد و روی هر هاست
استاتیک کار می‌کند.

### راه ۴ — فقط برای دیدن روی کامپیوتر (بدون نصب)

```
python serve.py
```

آدرسی مثل `http://192.168.1.10:8443` چاپ می‌شود که با گوشی هم می‌توانید بازش
کنید و **ویرایش کنید**، فقط دکمه «نصب» نمی‌آید.

## نصب روی آیفون

در آیفون فقط مرورگر **Safari** پشتیبانی می‌کند: روی دکمه اشتراک‌گذاری بزنید و
«Add to Home Screen» را انتخاب کنید. (باز هم باید آدرس `https` باشد.)

## فایل‌های این پوشه

| فایل | کار |
|---|---|
| `apartment-charge.html` | خود برنامه (تک‌فایل، بدون وابستگی به اینترنت) |
| `manifest.webmanifest` | مشخصات اپ برای نصب (نام، آیکون، رنگ) |
| `sw.js` | Service Worker برای کار کردن آفلاین |
| `icons/` | آیکون‌های برنامه |
| `serve.py` | سرور محلی برای دیدن برنامه روی گوشی در وای‌فای |
| `serve.cmd` | همان سرور با دوبار کلیک |
| `share_https.py` | ساخت آدرس موقت https برای نصب روی گوشی |
| `build_publish.py` | ساخت پوشه `publish` برای آپلود روی هاست |
| `tools_make_icons.py` | بازسازی آیکون‌ها در صورت نیاز |

## استفاده روزمره

**مدل محاسبه شارژ:** شارژ هر واحد = «تعداد نفرات ساکن × نرخ شارژ هر نفر».
نرخ پیش‌فرض ۴۰۰٬۰۰۰ تومان برای هر نفر است و در «تنظیمات» قابل تغییر است.
تغییر نرخ، فقط روی ماه‌های جدید اثر می‌گذارد؛ اگر می‌خواهید یک ماه خاص نرخش
فرق کند، همان ماه را باز کنید و نرخ را همان‌جا عوض کنید.

**هزینه‌های مشاع** (آسانسور، برق، آب، نظافت، تعمیرات و ...) فقط **ثبت و
دسته‌بندی** می‌شوند و روی مبلغ شارژ واحدها اثری ندارند.

**صفحه‌های برنامه:**

| صفحه | کار |
|---|---|
| 🧾 شارژ ماه | شارژ یک ماه، پرداختی‌ها، مانده هر واحد |
| 📅 گزارش سال | عملکرد ۱۲ ماه و جمع سالانه هر واحد |
| 👥 واحدها | نفرات هر واحد و مشخصات ساختمان |
| ⚙️ تنظیمات | نرخ شارژ، انواع هزینه مشاع، پشتیبان‌گیری، نصب |

**خروجی PDF:** دکمه‌های «خروجی PDF» در صفحه گزارش سال (کل سال یا رسید همه
واحدها) و در صفحه شارژ ماه. خروجی استاندارد چاپ کروم است؛ در گوشی گزینه
«ذخیره به‌صورت PDF» را بزنید. گزارش برای کل ۱۲ ماه سال کار می‌کند.

## مهم: پشتیبان‌گیری

داده‌ها در حافظه خود مرورگر ذخیره می‌شوند. اگر حافظه مرورگر پاک شود (یا برنامه
را از صفحه اصلی حذف و داده سایت را پاک کنید) اطلاعات از بین می‌رود.
**هر ماه یک‌بار** از «⚙️ تنظیمات ← خروجی فایل پشتیبان» یک فایل بگیرید و در
جای امنی نگه دارید. برای برگرداندن، «بازگردانی از فایل» را بزنید.

دکمه «حذف داده‌های قدیمی‌تر از یک سال» هم برای سبک نگه داشتن برنامه است.

## ثبت چندباره یک هزینه (ردیف‌های تکراری)

اگر یک هزینه در ماه چند بار تکرار می‌شود (مثلاً تعمیرات در سه مرحله، یا دو
قبض برق)، لازم نیست خودتان دستی جمع بزنید. در کارت «💸 هزینه‌های مشاع ماه»:

- زیر هر هزینه دکمه **➕ افزودن ردیف** را بزنید تا یک ردیف جدید باز شود.
- هر ردیف دو خانه دارد: **مبلغ** و **شرح** (مثلاً «مرحله ۱ تعمیر درب»).
- جمع آن هزینه، خودکار بالا کنار نامش نشان داده می‌شود و در جمع کل ماه هم می‌آید.
- برای حذف یک ردیف، ✕ همان ردیف را بزنید.

برچسب شرح اختیاری است، ولی اگر بنویسید در **خروجی PDF** هم زیر نام همان هزینه
به‌صورت ریز نمایش داده می‌شود؛ یعنی ساکن می‌بیند که مبلغ از چه چیزی تشکیل شده.
اگر یک هزینه فقط یک ردیف داشته باشد، در PDF ساده و بدون ریز نمایش داده می‌شود.

## پشتیبان خودکار ماهانه

در «⚙️ تنظیمات ← پشتیبان خودکار ماهانه» می‌توانید این قابلیت را روشن یا خاموش
کنید. این گزینه **به‌صورت پیش‌فرض روشن است**.

**چطور کار می‌کند:** در اولین باری که برنامه را در هر ماه باز کنید، یک نسخه
پشتیبان از کل اطلاعات همان لحظه ساخته می‌شود و داخل خود گوشی نگه داشته
می‌شود. برچسب هر نسخه، نام ماهی است که تازه تمام شده — مثلاً نسخه‌ای که اول
آبان گرفته می‌شود با نام «مهر» ذخیره می‌گردد.

**نکته مهم:** این نسخه‌ها مستقل از داده اصلی هستند. یعنی اگر داده اصلی خراب
یا اشتباهی پاک شد، نسخه‌های پشتیبان سالم می‌مانند و می‌توانید برگردانید.

**فهرست نسخه‌ها** پایین همان کارت می‌آید و برای هر نسخه سه کار می‌شود کرد:

- `⬇️ فایل` — دانلود همان نسخه به‌صورت یک فایل JSON
- `♻️ بازگردانی` — برگرداندن اطلاعات به همان لحظه
- `✕` — حذف آن نسخه

**تعداد نسخه‌های نگهداری:** پیش‌فرض ۱۲ نسخه (یک سال) است و تا ۲۴ قابل افزایش
است. با پر شدن سقف، قدیمی‌ترین نسخه خودکار حذف می‌شود.

**دکمه‌های دیگر:**

- `📥 گرفتن نسخه پشتیبان همین حالا` — بدون منتظر ماندن تا ماه بعد، همین حالا
  یک نسخه می‌سازد و دانلود می‌کند.
- `💾 ذخیره همه نسخه‌های آرشیو در یک فایل` — همه نسخه‌های موجود را در یک فایل
  می‌ریزد تا بیرون از گوشی نگه دارید.

اگر حافظه مرورگر پر شود، برنامه اول نسخه‌های پشتیبان قدیمی را آزاد می‌کند تا
داده اصلی سالم بماند؛ چون اطلاعات جاری از نسخه‌های پشتیبان مهم‌تر است.
